# 📘 Git & GitHub Essentials

A quick reference for the most common Git and GitHub concepts, commands, and workflows.

---

## 🔧 Core Git Concepts

- **Repository**: A Git project directory with version history.
- **Commit**: A snapshot of your staged changes.
- **Branch**: A parallel line of development.
- **Merge**: Combine changes from different branches.
- **Rebase**: Reapply commits onto another branch.
- **Staging Area**: Where changes go before committing.

---

## 🔤 Essential Git Commands

```bash
git init                    # Initialize a new repo
git clone <repo-url>       # Copy a remote repo
git status                 # Show current status
git add <file>             # Stage changes
git commit -m "message"    # Commit staged changes
git log                    # Show commit history
git branch                 # List or create branches
git checkout <branch>      # Switch branches
git merge <branch>         # Merge into current branch
git pull                   # Fetch & merge from remote
git push                   # Push changes to remote
